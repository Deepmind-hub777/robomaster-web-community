# EP Core 教室现场验收清单

## A. 摆场与记录

- [ ] 记录日期、场地、路由器/AP 型号、SSID 分区、机器人固件、SDK 版本、Windows 版本、浏览器/设备版本。
- [ ] 机器人在平整、干燥、无障碍区域；运动路径净空，旁边有观察员和人工急停手段。
- [ ] 使用低速默认档；填写准确速度上限（m/s）。
- [ ] 安装代表性教学载荷；记录载荷质量、固定位置、总质量，并确认不超过设备额定值。
- [ ] 运动试验前后确认电池电量；记录电量。
- [ ] 将 `probe.py` 输出、浏览器日志、外部高速摄像记录和现场照片放入同一轮次目录。

## B. 三项 go/no-go 指标

| 指标 | 测法 | 采样量 | 目标/判定 |
|---|---|---:|---|
| 本地浏览器路径 | Android Chrome、iOS Safari/iPadOS Safari、Windows Edge/Chrome 分别冷启动；记录本地网络权限、证书信任、WSS、WebRTC ICE 和媒体是否成功，并测 bridge 重启后的恢复 | 每设备 10 次冷启动 + 10 次恢复 | 每个平台都可稳定建立并恢复；失败需记录具体阶段 |
| 视频 glass-to-glass | 机器人视野中显示闪烁 LED/计时器；同一高速摄像机同时拍到场景事件和浏览器画面；分别测 H.264 直通与转码路径 | 每路径、设备、网络条件至少 100 个事件 | 两条路径分别报告 p50/p95/max；目标 p95 ≤250 ms；记录冻结/丢帧、bridge CPU 和分辨率 |
| 控制输入到运动 | 高速摄像机同时拍到按键/屏幕输入标记与机器人轮子/车体起动；脚本 command RTT 和车体速度遥测作为辅助数据 | 每设备/条件至少 100 次 | 报告 p50/p95/max；目标 p95 ≤150 ms。命令应答或速度遥测不能替代物理起动时间 |

**视频路径标签**：`h264-passthrough`（不解码/重编码，只做必要封装/packetization）与 `transcode`（解码后编码成浏览器兼容流）。两个路径分别开目录、分别测；若当前探针只跑到 SDK 解码帧，请标注为 `sdk-decoded-only`，不得冒充 transcode/WebRTC 数据。

## C. 停控与滑行距离

硬条件：低速默认档、运动中、带载荷；每个故障类型至少 30 次，所有试验都必须触发停控（30/30，100%观察成功）。每次都记故障发生、检测/租约到期、发出停止、实际完全静止四个时间点；记录总时间和故障点到静止的最大滑行距离。

| 阶段/指标 | 口径 | 目标 |
|---|---|---:|
| 心跳/检测窗口 | 心跳 100 ms；比较连续丢失 3、4、5 次，验证丢包不误停与故障能及时检测 | 检测/租约窗口 300–500 ms |
| 判定后制动 | 从停止命令发出到实际静止 | ≤500 ms |
| 故障到完全静止总时间 | 从故障注入真实开始到车体完全停止 | 最大值 ≤1000 ms；不使用 p95 替代 |
| 滑行距离 | 从故障发生点到完全停止点；高速录像旁放带刻度地垫/标尺 | 最大值 ≤30 cm |

故障类型分别测试 30 次：

| 故障注入 | 30 次全部停控 | 最大总停稳时间 | 最大滑行距离 | 备注 |
|---|---|---:|---:|---|
| 控制租约超时/停止心跳 |  |  |  |  |
| 学生浏览器关闭/标签崩溃 |  |  |  |  |
| Wi-Fi 断连/漫游 |  |  |  |  |
| bridge 进程强制结束 |  |  |  |  |
| Windows 睡眠/唤醒 |  |  |  |  |

`probe.py` 每次运行写一组 SDK 事件 JSONL/CSV；它仅能做单次“命令超时且 Python 进程存活”试验，不会自动执行 30 次，也不会把物理停稳/距离推断成已测数据。请为每种故障单独重复 30 次，在本表或另建现场记录表登记结果，并附高速录像。浏览器关闭、Wi-Fi 断连、bridge 崩溃、系统睡眠只能在运动测试区由观察员手动注入；当前脚本不会实现或伪装这些故障测试。SDK timeout 是同进程计时器，不证明进程崩溃时机器人会自动停。

## E. 收尾

- [ ] 停止视频流和控制会话，确认车体静止。
- [ ] 复核每种故障恰好记录 30 次，缺失/未判定也单独说明。
- [ ] 任何一次未触发、总停稳时间 >1000 ms、滑行距离 >30 cm：标记 **NO-GO**，不进入课堂试用。
- [ ] 比较两种视频路径的端到端延迟、兼容性和主机负载；据实选择，不预设直通一定优胜。
